# 七牛融合资源包计费设计

## 目标

将七牛模型从“公开美元按量价加成”切换为“融合资源包抵扣 Token”计费，并保证用户看到的积分扣费与实际售卖口径一致。

## 商业参数

- 资源包成本：323 元 / 1 亿基准抵扣 Token。
- 对外定价：350 元 / 1 亿基准抵扣 Token。
- 积分售价：1 元 = 20 积分。
- 最终价格：7000 积分 / 1 亿基准抵扣 Token。
- 毛利率：`(350 - 323) / 350 = 7.71%`。

## 七牛文本模型

七牛官方定义：`抵扣系数 = 目标计费项人民币价格 / 0.004 元每千 Token`。
平台目标为：`每百万实际 Token 积分 = 抵扣系数 × 70`。

同步器继续读取七牛公开模型目录中的人民币 `unit_price`、计价单位和阶梯范围，但不再使用 `unit_price_usd` 和 `QINIU_MODEL_PRICE_MARKUP`。同步器根据运行时自定义积分展示倍率，把目标积分换算成现有 tiered billing expression 所需的内部系数。同步周期保持 24 小时。

## SF-gpt-image-2

删除固定按张价格，改用上游返回的 Token 用量：

```text
抵扣 Token = 文本输入 × 9 + 图片输入 × 14.4 + 图片输出 × 54
积分 = 抵扣 Token × 7000 / 100000000
```

映射到现有比例计费：`ModelRatio=4.63235294117647`、`ImageRatio=1.6`、`CompletionRatio=6`。

## 安全边界

- 不修改用户余额、兑换码和历史日志。
- 普通失败请求继续全额退回预扣额度。
- 同步失败、人民币价格缺失、单位异常、毛利不足或价格阶梯异常时保留上一版生产配置。
- 部署前备份相关 options；部署后用文本模型和 SF 图片模型各做一次真实扣费核验。
